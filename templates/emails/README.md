# Modèles d'emails locatifs

Bases utilisées par le skill `emails-locatifs`. Variables entre `{{ }}`. À adapter au ton de votre agence — et si vous utilisez [memoria](https://memoria.immo), vos propres templates d'agence priment sur ceux-ci.

| Fichier | Situation |
|---|---|
| `reponse-lead.md` | Premier contact après un lead portail |
| `invitation-visite.md` | Proposition de créneaux de visite |
| `demande-pieces.md` | Pièces manquantes au dossier |
| `acceptation.md` | Candidature retenue |
| `refus.md` | Candidature non retenue |
| `accuse-preavis.md` | Accusé de réception d'un préavis de départ |
